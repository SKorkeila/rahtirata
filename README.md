# Rahtirata

A browser-based sci-fi trading and logistics sandbox. Start with one worn freighter and a hold full of metal,
trade between stations and moons, build production chains, found a trading house and rise to lead the Trade Council.

**Play:** https://skorkeila.github.io/rahtirata/ (runs in the browser, no installation; saves stay in your browser).
Available in English, Finnish and German.

**Feedback and bug reports:** [Issues](https://github.com/SKorkeila/rahtirata/issues).

This repository contains only the published game build. It is updated automatically from a private source repository
for each release.
